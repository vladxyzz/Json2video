# Json2vid Studio

## Visual system
An editing desk: quiet graphite navigation and code surface, paper-white controls, a full-height video monitor and an explicit scene strip. The user supplied JSON2Video as a functional reference; preserve the recognisable editor → preview → render workflow. Lime marks the main render action and timeline playhead. Body type uses a clean sans-serif; code and time measurements use monospace. No marketing hero.

## Composition
Desktop: narrow persistent sidebar, project toolbar, code pane and preview pane, timeline below. Other views reuse the workspace chrome for render history, examples and API integration instructions. On phones navigation becomes a compact horizontal row and panels stack. Focus, errors, progress, empty states and download results use the same layout.

## Direction contract
Make the first real render achievable without credentials or external assets, with a deliberately typographic three-scene example. Preview is explicitly schematic until a rendered MP4 exists. Real jobs only in history. The green primary action remains readable with near-black text. Job status is always text, not color alone.
